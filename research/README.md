# 정보 수집 및 검수

- 1차 출처: 칼라미티 공식 위키 (wiki.gg). 바닐라와 Calamity 본편만 포함.
- 먼저 목록 확보 후 개별 페이지의 사실을 자체 문장으로 정리한다. 원문 일괄 다운로드나 크롤러는 허용 확인 전 사용하지 않는다. [wiki.gg FAQ](https://support.wiki.gg/wiki/FAQ)
- 수집 기록에는 출처 URL, 확인 날짜, 적용 버전, 검수 상태를 유지한다. 불명확한 값은 null로 기록하고 추정하지 않는다.
- 위키 기반 작성 → 위키 내부 검수 → 실제 게임/소스 코드 교차 검증 순서. 교차 검증에서 발견한 불일치와 추가 정보는 별도 기록 후 반영한다.
- 추천은 절대 성능 순위로 단정하지 않는다. 난이도와 해금 조건을 기록한다.
- 번역문이나 이미지를 재사용하기 전 해당 라이선스와 저작자 표시 요건 확인.
- 공개 데이터는 data/에 별도로 작성. 현재 수집 목록만 등록했으며 실제 게임 정보는 아직 미수집.
