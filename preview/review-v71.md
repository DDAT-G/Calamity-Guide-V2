# V71 미니 공략 참조
심화 1~3장 5 STEP의 준비물·직업 장비·전략/이후 계획에서 57개 연결 항목, 88개 원본 세부 주제(3개 구조화 페이지 포함) 연결. 제목과 세부 주제 유일성 및 대상 존재 확인. 원본은 기존 walkthrough/extra/structured 데이터에서 직접 조회하며 내용 복사 없음. 참조 없는 항목은 버튼 없음. 인라인 펼침, 원본 임시 이동, 돌아가기 시 페이지·스크롤·펼침 상태 복원 구현. 신규 게임 내용 및 이미지 변경 없음. JS 문법 및 데이터 연결 검사 통과; 실제 브라우저 UI, 키보드 접근성과 미니 도감 상호 작용은 미실행. 후반부는 다음 빌드 개편 후 적용.
